UN PROCESO ACOMPAÑADO

Tu criterio marca el camino.

1. Reúne las evidencias

Descarga un ZIP con la aplicación de escritorio o mediante el servidor local. También puedes abrir un paquete anterior aquí, sin conexión con Canvas.

2. Prepara la evaluación

Genera la plantilla JSON con los identificadores reales de la rúbrica. Evalúa las evidencias en tu chat habitual, revisa los puntajes y aprueba el resultado. Esta app no utiliza la API de OpenAI ni evalúa automáticamente.

3. Valida y registra

Importa el JSON aprobado, conecta el servidor local y valida contra Canvas. Revisa la vista previa y confirma el registro. Descarga el reporte y verifica SpeedGrader.

Publicación y privacidad

GitHub Pages sirve archivos estáticos; la conexión con Canvas se realiza en tu equipo con el servidor Python. El sitio no guarda el token, archivos ni calificaciones en GitHub. Los datos se eliminan de la interfaz al recargar.
